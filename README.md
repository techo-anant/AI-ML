# AI-ML

This is just a personal AI/ML learning repo where I'm using Andrej Karpathy's YouTube videos to learn machine learning and neural networks.

## Contents

- **Micrograd/** – autograd engine, bigram model, MLP, batch norm, manual backprop, WaveNet
- **Makemore/** – character-level name generation
- **Transformers/** – bigram model, decoder-only GPT, and a GPT-2 training script (`gpt_2/`)
- **Tokenization/** – Byte Pair Encoding and modern LLM tokenizers
